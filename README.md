## Repository structure

| Directory | Contents                                              |
| --------- | ----------------------------------------------------- |
| `pi/`     | Raspberry Pi backend, frontend and installation tools |
| `esp32/`  | ESP32 firmware                                        |
| `config/` | Example configuration files                           |
| `docs/`   | Project documentation                                 |
