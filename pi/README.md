# Wombot Raspberry Pi

This directory contains the software that runs on the Wombot Raspberry Pi.

## Components

- `backend/`: FastAPI backend and WebSocket communication
- `frontend/`: Browser-based rover control interface
- `requirements.txt`: Python dependencies
- `install.sh`: Initial software installation script

## Installation

Clone the repository onto the Raspberry Pi, then run:

```bash
./pi/install.sh
```
